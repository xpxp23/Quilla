# Quilla (羽墨) v0.5 🖋️

> **轻巧灵动，落墨成章** —— 基于 Rust + Tauri v2 + CodeMirror 6 Lezer AST 打造的高性能现代化所见即所得（WYSIWYG）Markdown 编辑器与本地双链知识库工作台。

---

## 📖 项目简介 (Introduction)

**Quilla（羽墨）** 是一款追求极致书写沉浸感、毫秒级冷启动与本地知识网络连接的现代 Markdown 桌面编辑器。

**Quilla v0.5** 选用 **Rust** 作为底层系统核心（基于 `ropey` $O(\log N)$ 增量文本绳与 `rayon` 多线程检索引擎），依托 **Tauri v2** 轻量级系统 WebView 架构，并在前端全面接入 **CodeMirror 6 原生 Lezer 增量语法树（`syntaxTree(state)`）** 与 **真实 DOM 几何 + Pointer Events 统一交互引擎**，完整实现了 **块手柄命令菜单（Turn Into / 克隆 / 移动）**、**思源笔记式大纲右键子树整体升降级**、**正文章节与代码块折叠**、**`![[文档#标题]]` 块级嵌入引用**、**YAML 属性可视化卡片**、**交互式双链知识图谱 (`Ctrl+G`)**、**本地时间机器版本历史 (`Ctrl+Alt+H`)** 以及 **微信公众号/知乎富文本复制与长图海报导出**。

---

## ✨ 核心特性 (Key Features)

### 1. ⚡ 真实 DOM 几何抓手与思源式大纲操控 (Block Handle & Outline Studio)
- **零偏移真实 DOM 几何 6 点抓手**：摒弃虚拟行高估算，直接基于 `contentDOM.children` 物理 `getBoundingClientRect()` 与 **悬停桥接锁（Hover Bridge Lock）** 定位，完美适配多级标题、超链接、公式与折叠块。
- **抓手左键/右键命令菜单**：点击或右键 6 点抓手即可唤起块级命令面板，支持 **Turn Into（一键转为 H1~H4 / 正文 / 有序无序任务列表 / 引用 / Callout / 代码块）**、**整块上下移动 (`Alt+↑/↓`)**、**克隆当前块 (`Ctrl+D`)**、**剪切/复制/删除整块**。
- **思源笔记风格大纲右键菜单**：侧边栏大纲支持右键 **升级/降级当前标题**、**带子标题整体升级/降级（Promote/Demote Subtree）**、**正文章节折叠/展开**、**新建同级/子章节**、**复制整章 Markdown 或 `![[#标题]]` 嵌入双链**。

### 2. ✍️ 一体式代码块卡片与纯粹所见即所得 (Unified Code Card & Pure WYSIWYG)
- **一体式围栏代码块卡片**：顶栏常驻显示语言切换器、**代码块折叠/展开**、**一键自动缩进格式化**、复制与编辑围栏按钮；底栏 ` ``` ` 在非编辑态自动收口为 `6px` 圆角底边，彻底消除底部空行误触；支持点击左侧行号直接选中整行代码，以及 `↑`/`↓` 方向键无感穿越代码块首尾围栏。
- **YAML Front Matter 可视化属性面板**：文档顶部 YAML 元数据自动渲染为精致的 Properties 属性键值表与彩色标签胶囊，点击即可切回源码编辑。
- **正文章节一键折叠**：标题行右侧内置折叠按钮与已折叠行数胶囊提示，支持收起/展开整章及下属子章节。

### 3. 🧠 块级嵌入引用与交互式双链知识图谱 (Transclusion & Knowledge Graph)
- **`![[文档名#标题]]` 块级/章节实时嵌入**：支持跨文档或同文档章节内容实时嵌入渲染，内建原位编辑与一键跳转源章节。
- **多级 `#父标签/子标签` 胶囊体系**：正文中书写 `#工作/周报` 自动渲染为可点击胶囊，点击即刻联动侧边栏标签云与 Rust `rayon` 多线程聚合检索。
- **交互式双链知识图谱 (`Ctrl+G`)**：内置力导向 SVG 关系图谱，支持 **1 跳邻域 / 2 跳关系 / 全局图谱** 切换、滚轮缩放、画布平移、节点拖拽、一度邻接高亮以及点击节点跳转或自动创建双链笔记。

### 4. 🕰️ 本地时间机器版本历史与多渠道发布套件 (Time Machine & Publisher Suite)
- **本地版本历史 · 时间机器 (`Ctrl+Alt+H`)**：每次保存与定点快照自动归档至本地历史库，内置 **逐行 LCS 可视化 Diff 对比视图（新增/删除行高亮）** 与一键无损回滚（回滚前自动备份且支持 `Ctrl+Z` 撤销）。
- **微信公众号 / 知乎内联富文本一键复制**：自动将全文样式内联化（Inline CSS），完美保留标题色块、引用、Callout、代码高亮与表格边框，直接粘贴至微信公众号后台或知乎专栏。
- **Word (`.doc`) 与社交长图分享卡片 (`.png`) 导出**：内置三套精选主题配色的长图卡片工作台（羊皮书卷 / 清晨薄荷 / 极客暗夜），支持一键生成高清分享长图或导出标准 Word 文档。

## ⌨️ 常用快捷键 (Shortcuts)

| 快捷键 | 功能描述 |
| :--- | :--- |
| `/` | 唤起斜杠命令面板（一键插入表格/流程图/Callout/公式/嵌入块/YAML） |
| `[[` / `![[` | 唤起双向链接补全 / 块级章节嵌入引用补全 |
| `Alt + ↑ / ↓` | 整块向上 / 向下移动（自动识别完整代码块/表格/列表） |
| `Ctrl + D` | 在下方克隆当前段落或完整语义块 |
| `Ctrl + G` | 打开交互式双链知识图谱 (Knowledge Graph) |
| `Ctrl + Alt + H` | 打开本地版本历史 / 时间机器 (Time Machine Diff) |
| `Ctrl + \` | 开启 / 关闭左右分屏对比编辑视图 (Split View) |
| `Ctrl + 1~6` / `0` | 切换 1~6 级标题 / 转为正文（光标自动落于标题文本右侧） |
| `Ctrl + N` / `Ctrl + W` | 新建文档标签页 / 关闭当前标签页 |
| `Ctrl + O` / `Ctrl + S` | 打开本地 Markdown 文件 / 保存当前焦点面板文档 |
| `Ctrl + P` | 快速文件漫游 |
| `Ctrl + F` / `Ctrl + H` | 查找与替换（支持正则表达式与 `$1` 捕获组替换） |
| `F9` / `F8` / `F1` | 打字机居中模式 / 专注阅读模式 / 完整快捷键指南 |
