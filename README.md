# Quilla (羽墨) v0.6 🖋️

> **轻巧灵动，落墨成章** —— 基于 Rust + Tauri v2 + CodeMirror 6 Lezer AST 打造的高性能现代化所见即所得（WYSIWYG）Markdown 编辑器与本地双链知识库工作台。

---

## 📖 项目简介 (Introduction)

**Quilla（羽墨）** 是一款追求极致书写沉浸感、毫秒级冷启动与本地知识网络连接的现代 Markdown 桌面编辑器。

**Quilla v0.6** 选用 **Rust** 作为底层系统核心（基于 `ropey` $O(\log N)$ UTF-16 精准增量文本绳与 `rayon` 多线程检索引擎），依托 **Tauri v2** 轻量级系统 WebView 架构，并在前端全面接入 **CodeMirror 6 原生 Lezer 增量语法树（`syntaxTree(state)`）** 与 **真实 DOM 几何 + Pointer Events 统一交互引擎**，完整实现了 **块手柄与右键批量命令菜单（Turn Into / 克隆 / 移动）**、**思源笔记式大纲多选与带子标题一键点选转换**、**顶部多文档标签右键管理**、**多语言代码块智能格式化与超长代码折叠**、**`![[文档#标题]]` 块级嵌入引用**、**YAML 属性原位编辑卡片**、**交互式双链知识图谱 (`Ctrl+G`)**、**本地时间机器版本历史 (`Ctrl+Alt+H`)** 以及 **深度兼容的 Word (`.doc`) / 社交长图海报 (`.png`) / 微信公众号富文本发布套件**。

## ✨ 核心特性 (Key Features)

### 1. ⚡ 真实 DOM 几何抓手与思源式大纲多选操控 (Block Handle & Multi-Select Outline)
- **零偏移真实 DOM 几何 6 点抓手**：直接基于 `contentDOM.children` 物理 `getBoundingClientRect()` 与 **悬停桥接锁（Hover Bridge Lock）** 定位，完美适配多级标题、超链接、公式与折叠块。
- **跨行/多块批量格式转换**：无论通过左侧 6 点抓手菜单还是编辑器右键菜单，框选多行文本块后均可一键批量转换为 `H1~H4`、普通正文、自动递增有序列表、无序列表、待办任务、引用块、Callout 提示卡或围栏代码块；支持跨多行选区一键添加/移除删除线（`~~`）、加粗、斜体、高亮与行内代码。
- **思源笔记风格大纲点选与多选批量更改**：侧边栏大纲内置实时标题筛选框，支持 `Ctrl/Shift + 左键` 多选章节后右键批量修改级别、相对升降级、折叠正文章节；单章节右键提供直观的 **当前标题级别点选矩阵 (`H1~H6/正文`)** 与 **带子标题整体转换点选矩阵 (`H1~H6`)**，并内置大纲跳转锁彻底消除点击大纲定位时视图乱跳。

### 2. ✍️ 一体式多语言代码块卡片与丝滑编辑体验 (Unified Code Card & Smooth Editing)
- **多语言代码格式化引擎**：代码块顶栏支持一键格式化 JSON、HTML/XML/SVG/Vue、SQL、C/Rust/TS/JS/Go/Java/CSS 花括号语言（含单行压缩代码自动换行展开与字符串安全感知）以及 Python/YAML/Shell 公共缩进规整；光标进入围栏首尾行或点击顶栏「围栏」按钮即可直接编辑 ` ``` ` 源码，超长代码块底部内置收起/展开底栏。
- **零闪烁鼠标拖拽框选与智能多级列表**：鼠标按住左键拖拽框选期间自动锁定行内 Widget 树，松开鼠标后再平滑揭露语法标记，彻底根治框选闪烁；多级有序/无序/任务列表回车续行或空项退格时精准回退至父级缩进与标记类型。
- **顶部标签页完整右键菜单**：支持右键顶部标签执行保存、另存为/重命名、在右侧分屏打开、在独立新窗口打开、复制文件路径/文件名、在资源管理器定位，以及关闭当前/其他/右侧/已保存标签。

### 3. 🧠 块级嵌入引用与交互式双链知识图谱 (Transclusion & Knowledge Graph)
- **`![[文档名#标题]]` 块级/章节实时嵌入**：支持跨文档或同文档章节内容实时嵌入渲染，内建原位源码编辑与一键跳转源章节。
- **YAML Front Matter 原位交互属性面板**：文档顶部 YAML 元数据自动渲染为精致的 Properties 属性键值表与彩色标签胶囊，直接点击任意属性值即可原位修改。
- **交互式双链知识图谱 (`Ctrl+G`)**：内置力导向 SVG 关系图谱，支持 **1 跳邻域 / 2 跳关系 / 全局图谱** 精准切换、滚轮缩放、画布平移、节点拖拽、一度邻接高亮以及点击节点跳转或自动创建双链笔记。

### 4. 🕰️ 本地时间机器版本历史与多渠道发布套件 (Time Machine & Publisher Suite)
- **本地版本历史 · 时间机器 (`Ctrl+Alt+H`)**：每次保存与定点快照自动归档至本地历史库，内置 **逐行 LCS 可视化 Diff 对比视图** 与一键无损回滚。
- **深度兼容 Word (`.doc`) 导出**：针对 Microsoft Word / WPS 专项优化，采用 `<s>` 标签彻底规避 `<del>` 触发 Word 修订批注框，将代码块转为带行号与语法着色边框表格，自动栅格化 Mermaid 矢量流程图并清理公式冗余标签。
- **自定义位置社交长图分享卡片 (`.png`) 导出**：支持三套精选主题配色（羊皮书卷 / 清晨薄荷 / 极客暗夜）与标准/宽屏尺寸切换，递归内联真实 DOM 样式与代码块自动折行，并弹出系统保存对话框由用户自由选择保存目录。

## ⌨️ 常用快捷键 (Shortcuts)

| 快捷键 | 功能描述 |
| :--- | :--- |
| `/` | 唤起斜杠命令面板（一键插入表格/流程图/Callout/公式/嵌入块/YAML） |
| `[[` / `![[` | 唤起双向链接补全 / 块级章节嵌入引用补全 |
| `Alt + ↑ / ↓` | 整块向上 / 向下移动（自动识别完整代码块/表格/列表） |
| `Ctrl + D` | 在下方克隆当前段落或完整语义块 |
| `Ctrl + G` | 打开交互式双链知识图谱 (Knowledge Graph) |
| `Ctrl + Alt + H` | 打开本地版本历史 / 时间机器 (Time Machine Diff) |
| `Ctrl + \` | 开启 / 关闭左右分屏对比编辑视图 (Split View) |
| `Ctrl + 1~6` / `0` | 切换 1~6 级标题 / 转为正文（支持多行选区批量转换） |
| `Ctrl + Shift + X` | 添加 / 移除删除线 `~~`（支持多行选区逐行智能包裹） |
| `Ctrl + N` / `Ctrl + W` | 新建文档标签页 / 关闭当前标签页 |
| `Ctrl + O` / `Ctrl + S` | 打开本地 Markdown 文件 / 保存当前焦点面板文档 |
| `Ctrl + P` | 快速文件漫游 |
| `Ctrl + F` / `Ctrl + H` | 查找与替换（支持正则表达式与 `$1` 捕获组替换） |
| `F9` / `F8` / `F1` | 打字机居中模式 / 专注阅读模式 / 完整快捷键指南 |
